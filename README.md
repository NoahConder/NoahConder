# Hi, I'm Noah 👋

**I build tools for WebRTC, VoIP, and real-time communications.**

I'm a Tier 2 Technical Support Technician at [SignalWire](https://signalwire.com/), where I investigate SIP signaling, WebRTC connectivity, media quality, and communications API integrations. I also build developer-focused tools in TypeScript, JavaScript, and Python to reproduce issues, inspect live call behavior, and make complex problems easier to diagnose.

## Featured projects

### [SignalWire Browser SDK v4 — All-in-One Example](https://github.com/NoahConder/V4-Browser-SDK-All-In-One-Example)
A React/TypeScript WebRTC dialer and diagnostic workbench built on the SignalWire Browser SDK v4. Supports phone, SIP, and Fabric calling, with live call-quality metrics, event logging, codec and device settings, pre-call checks, and diagnostic exports.

### [SignalWire Network Test](https://github.com/NoahConder/signalwire-network-test)
A browser-based network troubleshooting tool that checks signaling, TURN connectivity over UDP/TCP/TLS, voice codecs, and video paths. Produces measurements and exportable results for support investigations.

### [Browser SDK v2 Example Improvements](https://github.com/NoahConder/browser-sdk-example-improvements)
An Express/JavaScript test harness for the legacy SignalWire Browser SDK, with call controls, device selection, ICE and codec configuration, event logs, and troubleshooting summaries.
